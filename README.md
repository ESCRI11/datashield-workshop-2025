# DataSHIELD Deployment Workshop — 2025

Hands-on materials for deploying a [DataSHIELD](https://datashield.org) node,
delivered at the DataSHIELD Conference 2025.

**→ [Read the workshop](https://escri11.github.io/datashield-workshop-2025/)**

DataSHIELD lets researchers analyse data across institutions without the raw
records ever leaving the institution that holds them. This workshop covers the
infrastructure side: getting a node up locally, then getting it safely onto the
network.

## What it covers

1. **Local deployment** — standing up Opal and Armadillo on your own machine, and
   how the two differ
2. **Going live** — what changes when the node leaves localhost
3. **Profiles** — adding analysis profiles to a running node
4. **Rock servers** — creating and wiring up the R execution backend

Built with [Quarto](https://quarto.org); the rendered site lives in `docs/`.
